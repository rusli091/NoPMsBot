# Variabel Lingkungan

## Variabel Lingkungan yang Diperlukan
* `TG_BOT_TOKEN`: Token Bot Telegram Anda, dari @BotFather
* `APP_ID`: ID Aplikasi Telegram Anda, dari my.telegram.org
* `API_HASH`: Hash API Telegram Anda, dari my.telegram.org
* `AUTH_CHANNEL`: ID Saluran Telegram, tempat bot harus meneruskan pesan.
* `DATABASE_URL`: URL basis data Anda.

## Variabel Lingkungan Opsional
* `TG_BOT_WORKERS`: Jumlah utas yang harus digunakan bot. Defaultnya adalah `4`.
* `COMMM_AND_PRE_FIX`: Awalan perintah Anda. Defaultnya adalah `/`.
* `BAN_COMMAND`: Perintah untuk memblokir pengguna. Defaultnya adalah `ban`.
* `UN_BAN_COMMAND`: Perintah untuk membuka blokir pengguna. Defaultnya adalah `unban`.
* `START_COMMAND`: Perintah untuk memulai bot. Defaultnya adalah `start`.
* `START_OTHER_USERS_TEXT`: Teks yang akan ditampilkan saat pengguna memulai bot.
* `ONLINE_CHECK_START_TEXT`: Teks yang akan ditampilkan saat admin memulai bot.
* `DERP_USER_S_TEXT`: Teks yang akan ditampilkan saat pengguna yang diblokir mencoba menggunakan bot.
* `IS_BLACK_LIST_ED_MESSAGE_TEXT`: Teks yang akan ditampilkan saat pengguna diblokir.
* `REASON_DE_LIMIT_ER`: Pembatas untuk alasan pemblokiran.
* `IS_UN_BANED_MESSAGE_TEXT`: Teks yang akan ditampilkan saat pengguna dibuka blokirnya.
* `BOT_WS_BLOCKED_BY_USER`: Teks yang akan ditampilkan saat bot diblokir oleh pengguna.
* `LOG_FILE_ZZGEVC`: Nama file log.
